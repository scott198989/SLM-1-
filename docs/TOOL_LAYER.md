# Model-independent engineering tools

The transplanted `forge_tools.engineering` is byte-identical to the pinned FORGE-1B calculator module. It has eight whitelisted functions: unit conversion, dimensional consistency, axial stress, ideal DC motor, free thermal expansion, underdamped second-order step, series RLC and real quadratic roots. Independent tests cover dimensional semantics, stress/safety factor, motor power balance, thermal intervals, reactance balance, initial/peak/steady response, quadratic residuals and refusal paths. These tests validate bounded implementations and assumptions; they do not certify arbitrary engineering designs.

`forge_tools.statistics` implements explicit contracts for Welch t-test/CI using Satterthwaite degrees of freedom, one-way ANOVA, full-column OLS regression, two-level factorial designs and known-baseline-sigma three-sigma SPC limits. This repairs the legacy pooled-df CI, broken ANOVA call and placeholder first-column regression. Independent numerical fixtures verify expected df, F statistic, multicolumn coefficients and orthogonal factorial levels. Assumptions remain in results. SPC does not claim Xbar-R constants, WECO rules, specification conformance or estimated process capability. DOE requires real levels, blocking, randomization and replication outside the coded matrix. Nonfinite inputs/results fail rather than producing serialized NaN.

The router accepts only exact named arguments, caps requests, retains an input hash and emits `COMPUTED`, tool version, result, assumptions and limitations. A numeric-claim check returns NOT_APPLICABLE when there is no numeric claim. Numerical agreement is scoped to that claim; units and physical assumptions require separate checks. No raw expression evaluation, arbitrary Python, network command or filesystem execution is accepted as a tool.

Future model integration should use validated JSON requests, explicit tool-call budgets, timeout and audit receipts, then return structured tool results as evidence. PRIME's useful task/workspace/assumptions/budget concepts can be implemented as an external controller around this contract; no random latent loops or confidence increments were transplanted. Retrieval is a separate private evidence tool with hash/location validation, not an alternative calculator. Test input and expected output are public development fixtures; they must not be counted as sealed gold evaluation or released SFT.
