# Nine-reference local catalog checkpoint

The private v25 `forge_reference.py` provides one catalog/find/quote interface
for all nine accepted academic reference packages. See the
[usage guide](../tools/academic_references/README.md) for commands and IDs.

Independent v24 review accepted the nine references only when their complete
JSON citation context remains attached: 1,274 artifact assertions, 56 tampering
probes, 16 scientific methods and 18 runtime methods passed. These counts overlap
in review scope and are not a count of distinct scientific validations. Its
report remains private in `reviewed-annotations-independent-review` in the
October 11 workspace. V25 pins that evidence as a separate acceptance record;
historical nested pending-review strings are deliberately preserved.

The wrapper loads captured, hash-verified bytes of the accepted v19 reference
runtime. It checks every package before emitting any result, then searches each
existing index independently. No merged index or global score ranking is added.
Quote and search results retain the entire original runtime response. The
readable view labels original source and separate reviewed annotation, then
appends the complete JSON record; all qualifications and citations survive.

The private catalog pins the exact approved chunk for each reference. Returned
text and citation dictionaries must equal that chunk, preventing a shortened
quote or metadata projection from silently passing. Drift in an unselected
package also refuses catalog/search/quotation. An error produces no partial
stdout result. The local launcher remains the trust anchor.

Owner validation passed 12 synthetic wrapper test methods, 222 assertions across
44 actual CLI calls, and 18 unchanged accepted-runtime regression methods.
Checks cover discovery/search and exact quote output for every reference,
full readable/JSON round trips, unsupported actions/queries, changed wrapper or
catalog pins, source/evidence/manifest/index drift, all SQLite sidecars, duplicate
IDs, package scope, annotation digest and full citation mismatch. These are
bounded development checks; independent review of the new wrapper is pending.

All 472 inventoried v17-v24 files, six owned-tool pins, 42 prior source/evidence
pins, five relation metadata inputs and the table register remain unchanged.
The accepted runtime, original quotes, annotations, receipts, family roles,
holds and indexes were not edited. The first synthetic fixture omitted the
chunk identifier required by the accepted quote protocol; it was corrected in
the test only. Initial failing logs are preserved in v25 and labeled historical.

Scope remains nine references, zero new SFT records and zero model-training
results. Copper numbers, JANAF substitutions, the clipped loop mark, unvalidated
coefficient tables and graph calibration remain unavailable. Protected pages
and sealed/related lab content were not opened. General Qwen generation is
unavailable. The eight-function calculation prototype stays separate and is
never invoked by this wrapper. No GPU, upload, push or source deletion occurred.
Native POSIX execution and the two earlier Windows file-symlink privilege cases
remain open; this checkpoint does not close those platform gaps.

The local v25 `review-target.json` pins the new code, frozen launcher/catalog,
actual command stdout, test evidence and preservation report. Independent review
should use a separate output workspace and verify discovery of all nine,
complete original citation/annotation context, fail-closed behavior and unchanged
old artifacts. Do not rerun package builders or rewrite frozen evidence in place.
