# One private static prose reference

The existing private citation index now supports a separate reviewed-prose
profile. This profile admits exactly one approved chunk, requires a reference-only
use policy and pinned evidence assets, and verifies those assets again before
returning cited text. Its status and scope are distinct from the calculator
reference pilot. Existing calculator manifests retain their behavior.

`forge_data.reference_excerpt` exposes two explicit operations:

- `find_reference`: lexical candidate search. A match is not a supported answer.
- `quote_reference`: exact quotation of an explicitly selected released chunk,
  with its source citation. It performs no interpretation or scientific calculation.

Other task types abstain. This is a closed task protocol, not a natural-language
answerability model. It loads no model and performs no training or embeddings.
